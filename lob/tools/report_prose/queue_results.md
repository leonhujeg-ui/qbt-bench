**真值规模**：1,000 万事件流上 192,918 个影子单探针（每 symbol 每 50 个事件一个；8 个 symbol），按时间前 70% 训练（135,042）、后 30% 测试（57,876）；流结束删失极少（T=10 s 时 898 个，占测试集 1.6%）。

**读法**：`Brier（常数）` 是用训练集全局成交率预测所有样本的底线；`Brier（训练）` 用于判断过拟合（与测试集差距 ≤ 0.01，无明显过拟合）；参数模型是最大似然拟合的指数形式，在该数据上劣于分桶模型（函数形式不对：成交概率对 `ahead/(μT)` 应是 S 形而非 1−e^{−x}），仅作对照。

未达成的原因（只用本节已有材料，未做新实验）：

1. **特征只看得到 t0 时刻的队列位置与强度**：d≥1 的挂单要先等价格走到自己的档位，这取决于合成流随机游走（漂移 + regime 切换）的未来路径，`ahead` / `rate_*` / `spread` 对此几乎无预测力——上表中 d=0→d=1 Brier 上升 0.03–0.10（四个 T 分别 +0.105 / +0.074 / +0.044 / +0.032），更高档不再单调（T=1 的 d=2→d≥3 反而下降 0.042）；而 d=0 不需要等价格，只需等前方量被吃掉，强度特征直接可用。原报告另称「常数预测在 d≥1 子集上 Brier 也 > 0.2」：此数字来自阶段 5 的作者记录，`results/` 中没有对应 JSON（探针 CSV 未入库），本次审核未能复核，不作为依据。原报告又称「8 组特征 / 分桶变体只把 T=1 的 Brier 从 0.183 降到 0.173」：同样没有入库 JSON，未能复核，不作为依据。
2. **shock regime**：t0 处于 shock 段的样本 Brier 比 normal 段差 0.01–0.06（下表：T=1/2/5/10 分别 +0.019 / +0.013 / +0.042 / +0.057），突发大单一次扫穿多档、价格跳变，t0 的队列位置与强度估计很快失效。
3. **删失不是原因**：影子单永不撤单，只有流结束删失（T=10 s 时 898 个，1.6%），对 Brier 的影响可忽略；第一版真实挂单探针因撤单删失过多而被弃用（原报告记为 54%，该数字来自阶段 5 的作者记录，`results/` 中无对应 JSON，未能复核）。
4. **合成数据**：事件流由带 regime 的随机过程生成，不含真实市场的自相关与隐藏流动性，本节数字只描述这份合成流，不能外推。

我们没有通过改变探针分布（例如只采触价档）来「制造」达标数字；表中的分段数字即是对不同使用场景的回答。
