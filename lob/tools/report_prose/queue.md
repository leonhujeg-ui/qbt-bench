## 5. 排队成交模型（方法部分）

**问题**：给定我方挂单在某价位的队列位置（前方可见量 `ahead`）、该档总量、档距触价 `d`、到达 / 撤单 / 成交强度估计，输出 T 秒内首次成交概率，并给出条件成交时间估计。

**真值**（`queue_collect.py`，`python -m lob.cli queue-collect`）：在 1,000 万事件回放中，每个 symbol 每 50 个事件随机取一侧、随机取前 5 档中的一档、随机取档内一张存活挂单作为「我方挂单」，在该时刻记录特征；之后跟踪这张订单在同一回放中的第一次成交时间与完全成交时间。订单在成交前被撤单 / 改量，或流结束早于 T，则该探针对该 T 删失（不计入评估）。生成器的撤单对象在存活单中均匀随机、与队列状态无关，因此删失是非信息性的。

**特征**：`d`（0 = 触价档），`ahead`（队列前方可见 lot），`level_total`，`rate_trd`（滑窗 2 s 内在该侧成交的 lot/s），`rate_arr` / `rate_cxl`（同侧挂入 / 撤单 lot/s），`spread`，regime 标签（来自生成器 sidecar，仅用于分段评估，不作输入）。

**校准方法（选择：分桶经验概率）**：桶键 = (`min(d,3)`, `u` 桶)，其中 `u = ahead / (rate_trd·T + 1)` 是「前方量 / 期望在 T 内成交的量」的归一化队列位置，`u` 桶边界 0.25/0.5/1/2/4/8/16；每桶概率 = `(k + α·g)/(n + α)`（α = 2，g = 全局成交率，拉普拉斯平滑）；成交时间估计 = 桶内已成交探针首次成交时间的中位数。选择理由：无分布假设、单调性由数据决定、每个数字可直接核对；对照组为最大似然拟合的参数模型 `p = 1 − exp(−e^{a_d}·(rate_trd·T + b_d)/(ahead+1))`（按 d 分别网格搜索 (a, b)）。

**评估协议**：按时间切分，前 70%（按探针时刻）训练、后 30% 测试；Brier = 测试集上 `mean((p − y)²)`；同时给出常数预测（全局成交率）的 Brier 作为底线、训练集 Brier 作为过拟合参照、按 regime 与按 d 的分段 Brier，以及 10 桶可靠性图（SVG，`results/queue_model/reliability_h*.svg`）。
